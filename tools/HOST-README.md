# DeckPilot Host 0.2.0

Распакуйте комплект на ПК, которым будете управлять с Deck.

**Linux:** откройте Setup-Linux.desktop и разрешите запуск, если файловый менеджер спросит. Запасной способ: `bash setup-linux.sh`. Мастер запросит sudo.

**Windows 10/11:** запустите Setup-Windows.cmd и подтвердите запрос администратора. Во время подключения используйте профиль сети «Частная».

На Deck установите deckpilot-0.2.0.zip через Decky Loader. Откройте DeckPilot и выберите подключение ПК.

Оставьте мастер на ПК открытым. Введите его восьмизначный PIN на Deck. После запроса сравните коды сверки на обоих устройствах. Если они совпадают, введите YES на ПК в течение минуты. Ключи доступа создаст мастер.

Steam Headless подключается по желанию на Linux-ПК. Если вы ещё не установили его, выберите управление питанием. Позже повторите этот мастер с выбором интеграции и добавьте её в настройках DeckPilot на Deck.

Подробности, системные изменения и границы проверок: MANUAL.md. На физической Steam Deck и Windows-ПК этот выпуск ещё не проверяли.
