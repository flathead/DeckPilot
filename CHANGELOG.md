# 0.2.0

Проект получил имя DeckPilot.

- Мастер подключения на Deck: выбор системы, вопрос о Headless, поиск ПК, PIN и короткий код сверки. Ключи создаёт мастер.
- Автономные помощники для Linux и Windows; запуск через desktop-файл или CMD.
- Headless по согласию пользователя: контроллер Ambxst либо существующий Docker-контейнер на Linux. Добавление после первой настройки и скрытие через настройки ПК.
- Импорт списка ПК из PC On/Off; сохранение прежнего SSH-ключа.
- Интерфейс использует элементы Decky, показывает ход команды и прячет адресные поля до раскрытия.

Windows и физическая Steam Deck требуют проверки на устройствах. Подробности выполненных проверок находятся в README.md.
